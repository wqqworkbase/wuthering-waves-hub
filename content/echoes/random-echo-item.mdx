Description[]

Random Echo Item is an Item Type in Wuthering Waves. An Item of this type contains one Echo that - depending on the item - is either random or can be chosen by the player from a list of Echoes. 

Despite the name of this Item Type, the Echoes these items give are never truly random. For example, the Rarity of the Echo obtained is the same as the rarity of the Random Echo Item it's obtained from.

Malleable Echo[]

Malleable Echoes allow the player to choose the Echo they will obtain from a list of Echoes. The list of Echoes to choose from is provided in the item's description. Malleable Echoes have an Attribute DMG Bonus Main Stat that matches their Sonata and the list contains Echoes from multiple Sonatas.

Malleable Echo items:

-  Malleable Elite Class Echo - Ragunna

-  Malleable Elite Class Echo I

-  Malleable Elite Class Echo II

-  Malleable Elite Class Echo III

-  Malleable Elite Class Echo IV
Molded Echo[]

Similarily to Malleable Echoes, Molded Echoes allow the player to choose the Echo they will obtain from a list. In the option list of a Molded Echo, all Echoes have the same Main Stat but different Sonatas. So far the Main Stat has been either Energy Regen, Crit. Rate or Crit. DMG.

Molded Echo items:

-  Molded Echo - Crimson Curtain Call I

-  Molded Echo - Crimson Curtain Call II

-  Molded Elite Class Echo I

-  Molded Elite Class Echo II
Morphable Echo[]

Morphable Echoes do not allow the player to choose their Echo. Instead, the Echo is random within the following limits:

- The Echo is already unlocked in the player's Data Bank i.e. the player has absorbed at least one Echo of the same kind

- Morphable Common Class, Elite Class and Overlord Class Echoes will give an Echo of said Class

- Morpable Echoes with a Sonata in their name give an Echo from that Sonata

The Rarity of Morphable Echoes obtained from Tacet Fields and Data Merging depends on Data Bank Level. Ones obtained from the Pioneer Podcast will be of the Rarity shown in the podcast's Rewards reel.

Morphable Echo items:

-  Morphable Common Class Echo

-  Morphable Echo - Empyrean Anthem

-  Morphable Echo - Eternal Radiance

-  Morphable Echo - Freezing Frost

-  Morphable Echo - Frosty Resolve

-  Morphable Echo - Lingering Tunes

-  Morphable Echo - Midnight Veil

-  Morphable Echo - Sierra Gale

-  Morphable Echo - Tidebreaking Courage

-  Morphable Elite Class Echo

-  Morphable Overlord Class Echo
