Dialogue[]

 Quest DescriptionThe Day 1 Campaign content has been updated. Maji is ready for you to join forces and take on the new tasks.

(Talk to Maji)
Maji: For this trial run, (&#8205;RoverThe player's chosen name for Rover&#8205;). I plan to merge the users as one group. A group I know best, the Lollo Logistics.
Maji: For them, the map is king. As long as...
Just as Maji is about to explain the details to you, the applet on the "Lollo Navigator' starts chiming...
Maji: See that? That's the call for action for "Lollo Navigator." I'm sending you the coordinates I just received.
Maji: To get familiarized with all the features, it's better to go and see for yourself.

(Defeat the enemies)
Maji: The program shows the color on this part of the map has changed. You did it, (&#8205;RoverThe player's chosen name for Rover&#8205;).
Maji: Remember "Lollo Hitman" from last time? I've loaded some of its features into this new program. The trips out in the wild can be tough, and emergencies can pop up any time.
Maji: If "Lollo Hitman" was a response measure for emergencies, then the new program acts as an early warning system.
Maji: Couriers can provide real-time feedback on road conditions to the "Lollo Navigator," which means the map is constantly being updated.
Rover: So your plan is to combine the map with the various services mentioned earlier?
Maji: Exactly. We also have other new services currently running in their trial phases. You've done a great job today. Let's try out the rest of the features some other time.
(Quest Complete)
