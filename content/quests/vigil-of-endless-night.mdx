Steps[]

- Seek Chenpi

- Go to the entrance of Woodveil Hall

- Enter "Woodveil Hall"

- Ski down the slope

- Freeze the time with "Chrono Sign" to activate the device

- Venture deeper

- Freeze the time with "Chrono Sign" to activate the device

- Pass through the tunnel and beware of the light beam security

- Venture deeper

- Freeze the time with "Chrono Sign" to activate the device

- Venture deeper

- Try to activate the Prototype Chronosorter

- Head to the first security node

- Reboot the first security node

- Head to the second security node

- Reboot the second security node

- Head to the upper tier of Woodveil Hall

- Create a path with Chronosorter

- Head to the upper tier of Woodveil Hall

- Head to the third security node

- Unlock the third security node

- Head to the fourth security node

- Unlock the fourth security node

- Go back to the Prototype Chronosorter

- Investigate the info tablet

- Head to the Prototype Chronosorter

- Defeat the rogue defense unit

- Activate the Prototype Chronosorter

- Tell Chenpi everything that happened in Woodveil Hall
Gameplay Notes[]

- Completing the "Seek Chenpi" step awards the player Chrono Sign.

- Completing the "Ski down the slope" step changes Chrono Sign into Activated Chrono Sign.

- Completing the quest awards the player the Exploration: Huanglong trophy Lesson Number 5: Live A Bit.
